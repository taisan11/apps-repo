## アプリの説明
### NetNovelViewer
ネット小説を見るためのアプリ  
現状、`なろう`、`カクヨム`、`ハーメルン`、`青空文庫`、`Tales`に対応しています。  
オフライン閲覧機能もあります!!  
### SimCamKun
シンプルで使いやすいカメラアプリです。  
標準アプリの代わりになるのを目指してます。  
### NativeTube
ネイティブUIのYoutubeです  
オフライン閲覧に対応しています。
